# Untangled for Python

Planned. The Python library of [Untangled](../README.md), to be published on
PyPI as `untangled` with the same CLI as the other languages.

This folder is licensed under the **GNU GPL version 2 only**, unlike the rest
of the repository, because it may port code from Martin Blais's
[snakefood](https://github.com/blais/snakefood), which is GPL. Code here must
never be copied into the MIT-licensed folders. Importing
[pydeps](https://github.com/thebjorn/pydeps) or
[grimp](https://github.com/seddonym/grimp) output is being considered as an
alternative to a new scanner.
